## Overview

A mapping and cleansing project for a group of construction companies. I replaced
project-by-project cost coding with one standard set of codes used on every budget.

## Context

Each project team could edit the cost code template freely, so every project ended up
coding its costs a little differently.

## Problem

Because the codes differed from job to job, spend could not be compared across
projects. Questions like "what does this kind of work usually cost us?" had no
reliable answer.

## Approach

- Extracted twelve months of cost codes for every job from the accounting system.
- Cleaned and compared them in Excel to see where projects agreed and where they
  drifted apart.
- Built one standard set of about a hundred codes for all future budgets.
- Allowed extra codes for genuinely unique work, while the standard set itself stays
  fixed.

## Tools

Excel, working from exports out of the accounting system.

## Status

Completed. Costs could be tracked and compared across projects on the same terms.
I have kept the details general here.

## What I learned

A standard only lasts if it leaves room for real exceptions. Giving teams a proper way
to add a unique code meant they had no reason to bend the standard ones.
